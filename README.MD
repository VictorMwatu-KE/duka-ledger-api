Duka Ledger API

A lightweight, self-hosted POS backend for small retailers – manage products, track cash/M-Pesa sales, verify transactions with OTP, and send SMS alerts via Africa's Talking.

---

Features

· ✅ Product Management – CRUD operations with stock levels and reorder alerts.
· ✅ Sales Engine – Create sales, deduct inventory in real time, and generate OTP for cash payments.
· ✅ OTP Verification – Secure cash transactions with 6‑digit OTP (sent via SMS or console fallback).
· ✅ Sales History – Filter by day, month, or year for admin dashboards.
· ✅ M-Pesa Ready – Endpoint structure supports STK push integration.
· ✅ PostgreSQL – Uses Neon or any PostgreSQL database.
· ✅ SMS Integration – Africa's Talking for OTP delivery.
· ✅ CORS Enabled – Works seamlessly with React frontend.

Tech Stack

Technology Purpose
Node.js + Express Backend framework
